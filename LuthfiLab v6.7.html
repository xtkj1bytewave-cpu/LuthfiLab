📘 Panduan Lengkap LuthfiLab (Winbox, Chrome Speedtest & YouTube)

1. PC / Laptop Virtual OS (Klik 2x pada PC/Laptop):
• Jika PC masih mati (LED merah), klik 2x akan langsung menyalakan PC dan membuka Desktop OS.
• Di dalam Desktop OS tersedia Google Chrome (untuk browsing, YouTube Streaming, dan Speedtest Bandwidth) serta Terminal / CMD.

2. Uji YouTube & Pemutaran Video:
• Klik tombol bookmark ▶️ YouTube di Chrome untuk membuka YouTube Player.
• Jika router Anda memblokir YouTube atau membatasi bandwidth via Simple Queue, pemutaran video atau tes kecepatan akan langsung menyesuaikan aturan router!

3. Blokir Situs & Limit Bandwidth via Router:
• Buka Router → Tab Firewall → Filter Rules untuk memblokir situs (cth: tiktok.com atau youtube.com).
• Buka Router → Tab Queues untuk membuat Simple Queue limit bandwidth.
