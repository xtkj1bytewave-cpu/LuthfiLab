📘 Modul LuthfiLab
🧭 Mulai di sini

LuthfiLab adalah laboratorium jaringan virtual. Bangun topologi di kanvas, konfigurasi perangkat lewat WinBox (klik 1x perangkat), lalu uji dengan Ping, Traceroute, dan Browser di PC.

  • Kanvas: seret perangkat untuk memindahkannya. Geser latar untuk pan, scroll untuk zoom. Tombol FIT menampilkan semua perangkat.
  • Kabel: tekan dock Kabel, lalu klik perangkat asal dan tujuan. Port bisa diubah di WinBox › Interfaces.
  • Klik 2x PC/Laptop: menyalakan dan membuka Desktop. Klik 2x router/switch: membuka Console.
  • Lab: pilih Lab di bagian atas. + Lab membuat Lab baru. Setiap Lab tersimpan sendiri.
  • Menu ⋯: Undo (Ctrl+Z), Packet Capture, Tantangan, Export/Import JSON.
  • VM Manager: PC, Laptop, dan Server sebagai mesin virtual dengan OS, login, console Linux, dan netplan.

Status: ✅ tersedia · ⚠️ sebagian (simulasi terbatas) · ❌ belum ada

🛠️ Alat bantu: Packet Capture, Undo, Tantangan, Console, VM
  • Packet Capture: menu ⋯ → Packet Capture. Menampilkan setiap hop paket dari Ping, Browser, DNS, dan Traceroute.
  • Traceroute: di Console PC/Server/VM, ketik traceroute 8.8.8.8.
  • Network Engine V8.3: paket hanya melewati perangkat dan interface yang aktif. Konflik IP aktif akan ditandai sebelum paket diteruskan.
  • Tantangan: menu ⋯ → Tantangan. Mengecek sendiri apakah konfigurasi Anda sudah benar.
  • Console: perintah seperti Terminal. Ketik help untuk daftar perintah.
  • VM Manager: buat VM, install OS, login, lalu atur IP static lewat sudo nano /etc/netplan/50-cloud-init.yaml dan sudo netplan apply.
